CATÁLOGO CONVITES PREMIUM

PUBLICAR
1. Crie um repositório GitHub e envie os arquivos index.html, style.css, script.js, config.js e a pasta assets.
2. Em Settings > Pages, escolha Deploy from a branch, branch main, pasta / (root).
3. No config.js, preencha o campo "whatsapp" com 55 + DDD + número (apenas dígitos).

ADICIONAR NOVO CONVITE
1. Prepare uma capa vertical 9:16 (1080 x 1920 é recomendado) em .webp, .jpg ou .png.
2. Envie a capa para a pasta assets do repositório. Exemplo: assets/jardim-encantado.webp.
3. Abra config.js e, dentro da lista "modelos", copie um dos objetos e altere:
   "id": identificador único sem espaços (ex.: "infantil-jardim-2")
   "categoria": exatamente "Infantil", "15 anos" ou "Casamento"
   "titulo": nome do modelo
   "imagem": caminho da imagem (ex.: "assets/jardim-encantado.webp")
   "link": URL HTTPS do convite publicado.
4. Separe os objetos por vírgulas e salve. O filtro "Todos" mostrará todos automaticamente.

Os 12 modelos originais foram preservados. O convite abre em outra aba; ao retornar, o cliente pode solicitar o modelo. O botão Peça o seu também abre o formulário diretamente.
O formulário envia modelo, nome, idade (quando aplicável), data, horário e tema pelo WhatsApp, sem preços ou adicionais. O cliente confirma o envio no WhatsApp.
